Embedded Linux Platform

Jetson Orin Nano、STM32、Linux driver 與 Yocto 的逐步實作教材。每一章對應 repo 裡的一個 Step（一個 PR），程式碼和教學章一起交付。

所有指令都假設你已經 clone 這個 repo，並在 repo 根目錄（有 ROADMAP.md 的那一層）執行，除非章裡另外註明。

  1. Step 1 · 建立開發環境基線

    環境檢查、Jetson 版本快照與接線紀錄。

  2. Step 2 · 最小 character device

    第一個 kernel module：/dev/edge_test，從 echo 一路追到 driver 的 write()。

  3. Step 3 · ioctl 控制通道

    共用 header、兩個 ioctl 命令與第一支 C++ CLI；ioctl 號碼為什麼是 ABI。

  4. Step 4-a · userspace GPIO：先點亮 pin 29

    第一次接上 LED：用 GPIO v2 uAPI 的 C++ 程式控制 line 105，並找出 JP6 開機時 pad 被 tristate 的坑。

  5. Step 4-b · platform driver + Device Tree

    用 overlay 描述 LED 與 pad 的 pinctrl 狀態，compatible 配對觸發 probe()，以 devm_gpiod_get() 控制 GPIO。
